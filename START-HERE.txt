AUTOBOT v0.13.1-beta.1 - CHOOSE A SETUP MODE
============================================

CLASSIC: ONE POSH ACCOUNT ON THIS COMPUTER

Open OPEN-FIRST-AUTOBOT-SETUP-GUIDE.pdf and use SETUP-MAC.command or
SETUP-WINDOWS.cmd. This is the original one-computer system and remains fully
supported.

MULTI-PROFILE HOST: 1-4 SEPARATE POSH ACCOUNTS ON THIS COMPUTER

Open OPEN-FIRST-AUTOBOT-PROFILE-HOST-GUIDE.pdf and use
SETUP-PROFILE-HOST-MAC.command or SETUP-PROFILE-HOST-WINDOWS.cmd. This secondary
system keeps each account in an isolated Chrome profile and gives the Command
Center a one-click Launch all workers control.

The two modes use separate local services and can coexist. Do not remove a
working classic pairing to try the profile-host system.


CLASSIC SECOND COMPUTER QUICK START
===================================

WHAT YOU NEED

- Google Chrome
- Node.js LTS from https://nodejs.org
- Permission to enable Chrome Developer mode
- An enrollment or one-time code from the AUTOBOT Command Center

OPEN THIS FIRST

Open OPEN-FIRST-AUTOBOT-SETUP-GUIDE.pdf in this package. It contains the full
Windows and Mac instructions, browser-popup settings, and copyable Terminal and
PowerShell commands.


1. DOWNLOAD AND EXTRACT

On GitHub, click Code, then Download ZIP. Double-click the ZIP to extract it.


2. CREATE AN ENROLLMENT CODE

- Open https://autobot-command-center.avgschnook.chatgpt.site
- Enter the dashboard PIN provided by the owner.
- Start a 48-hour enrollment for the planned number of laptops, or create a
  one-time code.

An enrollment code works for the selected number of laptops for 48 hours.
Each enrolled laptop must be approved in the dashboard. A one-time code still
works once and expires after ten minutes.


3. RUN THE SETUP ASSISTANT

Windows:
- Double-click SETUP-WINDOWS.cmd.

Mac:
- Double-click SETUP-MAC.command.

The assistant installs AUTOBOT, asks for the code and laptop name, registers
automatic startup, and starts the device bridge.

UPGRADING AN ALREADY CONNECTED LAPTOP
-------------------------------------
Run the new setup file from the extracted v0.13.1 folder. It keeps the saved
pairing and updates the startup path without asking for another code. Remove the
old unpacked AUTOBOT extension in chrome://extensions, load the new extension
folder, then restart the computer once. Do not remove or revoke the laptop in
the Command Center before upgrading.

If you used the assistant, skip manual steps 4, 6, and 7 below. Complete step 5
to load the extension, then continue with step 8.


MANUAL ALTERNATIVE — OPEN A TERMINAL IN THE AUTOBOT FOLDER

Windows:
- Open the extracted autobot folder.
- Click the File Explorer address bar, type powershell, and press Enter.

Mac:
- Open Terminal, type cd, and then press the spacebar once.
- Drag the extracted autobot folder into Terminal and press Enter.


4. INSTALL

Run:

  npm install


5. LOAD THE CHROME EXTENSION

- Open chrome://extensions
- Turn on Developer mode.
- Click Load unpacked.
- Select the extension folder inside the extracted autobot folder.
- Confirm AUTOBOT Owned-Event RSVP Lab v0.13.1 appears.


6. PAIR THE COMPUTER

Replace PAIRING_CODE and run this in the terminal:

  npm run device:pair -- --controller=https://autobot-command-center.avgschnook.chatgpt.site --code=PAIRING_CODE --name="Friend Laptop"

It should say: Paired Friend Laptop.


7. START THE DEVICE BRIDGE

Run:

  npm run device

Keep this terminal open during the test.


8. CONNECT THE POSH TEST PAGE

- Sign into POSH normally and complete OTP/CAPTCHA checks manually.
- In the dashboard, enter the organizer-owned event URL, click Select online,
  and click Open event on selected devices.
- Find the AUTOBOT panel in the lower-right corner.
- Leave Allow command center checked.
- Approve Friend Laptop in the dashboard.
- Confirm Friend Laptop appears online in the dashboard.
- Run a Rehearsal first. Rehearsal does not select or submit an RSVP.
- For a live test, the owner selects only the laptops participating that day.
  Each selected laptop receives one independent, one-use execution lease.
- After the organizer resets the mock tickets, use Reset selected devices in
  the Command Center to clear those laptops and activate them again.
- For live mode, keep the POSH event tab visible. Prepare + activate opens and
  verifies the assigned ticket selector early without changing quantity.


OPTIONAL AUTO-START

After everything works, run:

  npm run device:install

For the current login session, still start the bridge with npm run device.


IMPORTANT

- Use only the organizer-owned free test event.
- POSH login, OTP, CAPTCHA, and payment data stay local.
- A password entered in the Command Center is encrypted separately for this
  device and decrypted only by its local bridge.
- Every computer can still operate independently using its local AUTOBOT panel.
- Pairing remains saved across restarts. The installed Mac and Windows startup
  service restarts the bridge if it exits. Keep Chrome and the event tab visible
  near the test time.
- Before returning a borrowed computer, ask the owner to click Remove and
  revoke, remove the extension, and delete the extracted AUTOBOT folder.
